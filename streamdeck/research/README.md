# Research notes for the Stream Deck pack

Notes gathered by research agents on 2026-11-06, each fact with its source and a
confidence (primary source / seen in real files / inferred). They're working material
for building the pack, not user documentation, and can go out of date as Elgato and
Cloud Imperium change things. `*.verified.md` files were re-checked by a second agent
against the primary sources; prefer them where both exist.

| file | covers |
|---|---|
| `sdk.md`, `sdk.verified.md` | plugin manifest, the raw WebSocket protocol, images, encoder and Neo layouts, property inspector, packaging, Node runtimes |
| `devices.md`, `devices.verified.md` | every Stream Deck model: grids, key sizes, dials, touch strips, SDK device types, profile model IDs |
| `profiles.md` | the `.streamDeckProfile` format (v2 and v3), page and folder layout, Hotkey settings, bundling profiles in a plugin |
| `navigation.md` | built-in actions as stored in profiles: folders, pages, switch profile, multimedia, website, dials |
| `iconpacks.md` | the `.streamDeckIconPack` format and icon guidelines |
| `plugins.md` | Discord, OBS, Volume Controller and other plugins as they appear in profiles |
| `starcitizen.md` | Star Citizen 4.x keyboard defaults and actionmaps, from the game's `defaultProfile.xml` |

`<scratch>` in the notes stands for the working folder the agents used; their downloads
and scripts weren't kept.
